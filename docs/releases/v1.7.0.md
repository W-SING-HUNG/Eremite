# Eremite Host v1.7.0

v1.7.0 brings the completed maintenance since v1.6.1, Emerald Pulse V1/V1.1 and the Ask initialization Enter repair into one source-first Host release.

## Changes since v1.6.1

- Failed native Tool Runs can be retried as a new Run with a separate output namespace. The original Run, fixed source versions and history are preserved, and current Host policy and destination are revalidated. Explicit Project root stays distinct from an omitted destination for File Converter and all five PDF operations. Bounded destination evidence and the compatible v1/v2 Retry display retain the original input snapshots.
- Backup validation checks the complete retained blob set, migration checksums and actual hashes, and rejects uncopied non-empty SQLite WAL. Failed file creation preserves shared or uncertain blobs. Native runtime settings support explicit executable paths and an existing short tool workspace root; non-default conversion profiles fail before execution.
- Emerald Pulse V1/V1.1 adds consistent dark-green surfaces, shared motion, reduced-motion handling, stable waiting/Tool indicators and Chinese-first local typography. Mobile titles retain complete accessible names; Markdown/Text reading sizes and zoom follow the 16px reading token. Streamed Markdown remains immediate.
- A non-composing Enter during Ask initialization now retains one explicit send request and dispatches once after successful Provider and conversation loading. Failures preserve the text. Editing, closing or changing context/conversation cancels the queued request; stale responses cannot replace the current selection. Created conversations remain usable after a list-refresh failure, and reopening clears old inline artifact errors. Shift+Enter, composition/229, streaming and Stop retain their contracts.

- Public submission checks cover source, staged bytes, proposed PR/release text and new commit messages. New author and committer addresses require GitHub no-reply identities in PR/main CI, with explicit allowances for legitimate dependency/model names and required attribution in content. Repository-local identity configuration and final server metadata checks supplement CI; this is not an absolute guarantee for every external submission path.

These capabilities were integrated through public [maintenance PR #2](https://github.com/W-SING-HUNG/Eremite/pull/2), [Emerald Pulse PR #4](https://github.com/W-SING-HUNG/Eremite/pull/4) and [Ask repair PR #5](https://github.com/W-SING-HUNG/Eremite/pull/5). This version preparation updates package/root-lock versions, support/release documentation and new-commit metadata validation; it does not upgrade dependencies, Suppliers, contracts or migrations.

## Installation and upgrade

Supported: Windows x64, Node.js `>=24.15.0 <25` (verified baseline 24.15.0). This is source-first: no installer, hosted deployment or npm publication. Use the source for tag `v1.7.0`, run `npm.cmd ci`, then the documented build/start scripts. The server binds to `127.0.0.1`; public interfaces, reverse proxies and port forwarding are outside the supported security boundary.

Before upgrading, create and verify an application backup and retain a separate copy. Do not copy a running SQLite database as a backup. Existing public v1.6.1/0012 data upgrades through the append-only `0013` migration. Keep real data outside disposable source/test roots; see [backup and restore](../backup-and-restore.md).

The fixed runtime archives are File Converter `1.1.3` (SHA-256 `566d03e5850d0fd966482f55028f136d809ed902801ecdad097abbc1ad2ba1c6`, Sharp 0.35.5) and PDF Tools `1.0.0-rc5` (SHA-256 `4d39776995930e449238272e01bc0e981d84a3ea93835bd40a7e280309dd3e36`). PDF Supplier retains its prerelease identity independently of this stable Host release. Its five operations require external qpdf exactly `12.4.0`. The 18 File Converter directions require the applicable Sharp, external Pandoc >=3.1 or external LibreOffice >=7.6 engine. qpdf, Microsoft VC runtime, Pandoc and LibreOffice are not bundled by the Host. Supplier source tags remain independent; File Converter's published source tag 1.1.2 does not identify the vendored 1.1.3 archive.

Host policy, authentication, confirmation, workspace isolation, output validation, File Lifecycle and Run History remain authoritative. AI stays optional, request-bound and draft-only until explicit user confirmation. No real external AI Provider acceptance is claimed for this release.

## Security and retained follow-ups

`source-map-js@1.2.1` retains the production-transitive **HIGH** advisory [GHSA-68fv-2mgg-jv7q / CVE-2026-93749](https://github.com/advisories/GHSA-68fv-2mgg-jv7q). The upstream patched version is 1.2.2. This release does not remediate it or claim zero vulnerabilities; Eremite exploit reachability remains NOT VERIFIED. See the dated release validation below for the actual audit and bounded path review. Dependency maintenance requires a separate reviewed change.

The fresh full audit on 2026-10-15 reports exactly this one HIGH finding, with no critical, moderate or low finding. The locked chain is Next 16.3.8 → PostCSS 8.5.23 → source-map-js 1.2.1. The bounded source review found no direct product import or identified user-input path into this source-map processing chain; this does not prove unreachability. Its existing FOLLOW-UP classification is retained independently of any historical metadata disposition.

Arbitrary long default LibreOffice profiles remain a FOLLOW-UP; the explicit existing short-root configuration is the accepted mitigation, not proof for every installation path. Backup appVersion metadata retains its historical 1.3.0 value; compatibility is determined by format, migration checksums and integrity. At 375px with no selected file, Ask can require scrolling below the initial viewport. Manual native IME acceptance, real external Provider behavior, broader platform support and whole-product absence of defects are NOT VERIFIED.

The existing UI acceptance and source-bound production Chrome evidence are reused from the integrated changes; no new visual audit is implied. Independent V1/V1.1 functional acceptance predates later closeout/Ask changes; local automated checks are not independent reacceptance. Preserve [LICENSE](../../LICENSE), [NOTICE](../../NOTICE), [third-party notices](../../THIRD-PARTY-NOTICES.md) and Supplier notices for the actual distributed files.
